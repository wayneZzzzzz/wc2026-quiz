# 世界杯竞猜 2026

## 启动步骤

### 1. 安装 Node.js
访问 https://nodejs.org/ 下载安装 LTS 版本（或用 Homebrew：`brew install node`）

### 2. 安装依赖
```bash
cd ~/竞猜
npm install
```

### 3. 启动服务
```bash
npm start
```

然后打开浏览器访问 http://localhost:3000

### 4. 管理员入口
- 访问 http://localhost:3000/admin
- 默认密码：`admin2026`
- 可通过环境变量修改：`ADMIN_PASSWORD=你的密码 npm start`

---

## 使用流程

### 管理员操作
1. 登录管理后台 `/admin`
2. 点击"添加比赛"，填写比赛信息和盘口选项
3. 比赛前一天点击"开放投票"（或系统自动在24小时前开放）
4. 比赛开始后点击"截止投票"（或系统自动在比赛时间截止）
5. 比赛结束后点击"公布结果"，选择正确答案，系统自动结算积分

### 用户操作
1. 访问网站，点击"加入竞猜"，输入昵称即可
2. 在赛程页面找到投票中的比赛，进入投票
3. 投票后可查看其他人的选择
4. 比赛结束后查看结果和排行榜

---

## 积分规则
- 每场基础分 **100 点**
- 猜中者平分所有猜错者的积分
- 猜错者扣除 100 分
- 排行榜分两个维度：积分 和 获胜场次
